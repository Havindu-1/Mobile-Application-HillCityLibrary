# Quick Start Guide - Shop Feature

## How to Use the Shop

### 🛍️ Shopping for Books

1. **Navigate to Shop**
   - Tap the **Shopping Cart** icon in the bottom navigation bar
   - You'll see the shop screen with all available books

2. **Browse Books**
   - Scroll through the grid of books
   - Featured books (NEW/BESTSELLER) appear at the top
   - Each card shows:
     - Book cover (genre placeholder)
     - Title and author
     - Star rating
     - Price (with discount if applicable)
     - Savings amount

3. **Filter by Category**
   - Tap category chips at the top (All, Fiction, Non-Fiction, etc.)
   - Books update automatically
   - Selected category is highlighted in blue

4. **Search for Books**
   - Use the search bar at the top
   - Type book title or author name
   - Results filter in real-time

5. **Add to Cart**
   - Tap the **+** button on any book card
   - Cart badge updates with item count
   - Item is added (or quantity increases if already in cart)

### 🛒 Managing Your Cart

1. **View Cart**
   - Tap the **cart icon** in the header (with badge showing count)
   - See all items in your cart

2. **Adjust Quantities**
   - Use **−** button to decrease quantity
   - Use **+** button to increase quantity
   - Quantity 0 removes the item

3. **Remove Items**
   - Tap the **trash icon** on any cart item
   - Item is removed immediately
   - Confirmation message appears

4. **Review Order**
   - See order summary at bottom:
     - Items subtotal
     - Discount savings (green)
     - Tax (5%)
     - Total amount

### ✅ Checkout

1. **Complete Purchase**
   - Review your order summary
   - Tap "Proceed to Checkout" button
   - Order is placed
   - Confirmation message with Order ID
   - Cart is cleared
   - Returned to shop screen

2. **Empty Cart**
   - If cart is empty, you'll see a friendly message
   - Tap "Continue Shopping" to return

## 💰 Understanding Pricing

### Price Display
- **Original Price**: Shown with strikethrough if discounted
- **Discounted Price**: Large, blue text - what you pay
- **Discount Badge**: Red badge shows percentage off
- **Savings**: How much you save per book

### Example
- Original: ₹599
- Discount: 20% OFF
- You Pay: ₹479
- You Save: ₹120

### Cart Total
- Subtotal: Sum of all items at discounted prices
- Discount: Total savings shown in green
- Tax: 5% of subtotal
- **Total**: Final amount to pay
